Five tools. Read-only today.

Every tool declares readOnlyHint, so hosts can let agents run them without confirmation prompts. Nothing is created, changed or stored — research first, actions when they can be that safe.

  • search_marketsFind symbols in the catalog — on-chain feeds, Treasury tenors, macro series, SEC registrants — plus recent headlines.read-only
  • research_assetLatest value, period change, drawdown and volatility, dated history and headlines for one symbol.read-only
  • compare_assetsAlign 2–6 symbols on shared dates, each in its own unit; mixed prices and yields are flagged, not blended.read-only
  • market_overviewPeriod changes for BTC, ETH, SOL, gold, SPY, QQQ, EUR/USD, US 2y and 10y yields and CPI in one call.read-only
  • company_fundamentalsLatest annual and quarterly financials with filing links for US-GAAP filers, from EDGAR XBRL.read-only

Full install guide
  1. Open Settings → Connectors in Claude and choose Add custom connector.
  2. Name it Nomina and paste the server URL. No sign-in is required.
  3. Start a chat and ask a market question — the five tools appear automatically.
https://mcp.nomina.io/mcp

Works on Claude Pro, Max, Team and Enterprise. A directory listing is in review; until it appears, the custom-connector route above is the way in.

FAQs

What people ask before they add it.

Is this financial advice?

No. Nomina returns the sources' published data and plain arithmetic derived from it — period changes, drawdown, volatility — as of the observation dates shown. It makes no recommendations and takes no actions.

Which assets have prices?

Anything with a Chainlink feed on Ethereum mainnet: major and mid-cap crypto, EUR/USD and other FX pairs, gold and silver, and a handful of US equities and ETFs such as SPY, QQQ, NVDA and TSLA. For US-GAAP filers, company_fundamentals covers filings data; prices are never invented.

Why on-chain prices instead of an exchange feed?

Because they are public and redistributable. Exchange and vendor feeds license data for internal use only; on-chain oracle values are public blockchain state anyone may read and show. The trade-off is disclosed in every answer: feeds update on heartbeat or deviation, so a day's close can lag an exchange close.

What does it cost?

Nothing. The hosted endpoint is free to use, the code is MIT-licensed, and no source requires a key. The hosted tier sleeps when idle, so the first request after a pause can take up to a minute.

Where does my data go?

Only the tool inputs — symbols, tickers, search terms, date windows — are sent to the public sources that answer them. Nomina keeps no logs of requests or conversations. Details in the privacy policy.
