# Nomina v1.2.0

v1.2.0 answers questions that need exact dates rather than fixed lookback periods, adds a
one-call market snapshot, reports drawdown and volatility for a researched series, and caches
identical provider requests for 60 seconds. All tools remain read-only.

## What's new

- `research_asset` and `compare_assets` accept `start` and `end` (`YYYY-MM-DD`, inclusive)
  for an exact window instead of `period`; responses report `period` as `start..end`.
  Windows are limited to 25 years and cannot end in the future.
- New tool `market_overview`: period returns for `^GSPC`, `^IXIC`, `^DJI`, `^RUT`, `^VIX`,
  `^TNX`, `DX-Y.NYB`, `GC=F`, `CL=F`, `BTC-USD`, `ETH-USD`, and `EURUSD=X`, with failed
  members listed individually.
- `research_asset` returns `statistics`: observation count, maximum drawdown, and annualized
  volatility of the returned series (sample standard deviation of log returns, √252 daily or
  √52 weekly). Descriptive only; not forecasts.
- Identical Yahoo Finance requests within 60 seconds reuse the previous response, reducing
  provider rate limiting during multi-step research.

## Install

- Claude Desktop: download `Nomina.mcpb` from the release and install it via Settings →
  Extensions → Advanced settings → Install Extension.
- Claude Code or any stdio client: `uv run --frozen --no-dev --directory <clone> server.py`.
- Gemini CLI: `gemini extensions install https://github.com/nomina-xyz/nomina-mcp`.

## Limits

Yahoo Finance's public endpoints can be delayed, incomplete, or rate limited, and its terms
restrict automated collection and redistribution — see
[Data sources and limits](https://nomina-xyz.github.io/nomina-mcp/data-sources/).
