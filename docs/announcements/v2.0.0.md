# Nomina v2.0.0

v2.0.0 replaces Nomina's data layer. Every source is now public-domain or licensed for display
and redistribution, so the tools can be listed in agent directories that require first-party
or legitimately licensed data. Yahoo Finance is no longer contacted.

## What's new

- **On-chain prices.** Crypto (BTC, ETH, SOL, LINK and ~80 more), FX (EUR/USD, GBP/USD, JPY/USD,
  …), gold and silver, and a small set of US equities and ETFs (SPY, QQQ, NVDA, TSLA, GOOGL)
  come from Chainlink Data Feeds read directly from the Ethereum blockchain through public
  JSON-RPC gateways. Daily closes are reconstructed from on-chain round timestamps; history
  goes back to each feed's launch.
- **US Treasury yields** — the daily par yield curve, 1 month to 30 years (`US2Y`, `US10Y`, …).
- **US macro series** — CPI, unemployment rate, nonfarm payrolls, average hourly earnings
  from the Bureau of Labor Statistics.
- **`company_fundamentals`** (new tool) — latest annual and quarterly revenue, income, EPS,
  balance-sheet and cash-flow figures with filing links for any SEC registrant, from EDGAR
  XBRL company facts.
- **Headlines** come from the GDELT Project (title, link, date, domain).
- `market_overview` basket: BTC, ETH, SOL, gold, SPY, QQQ, EUR/USD, US 2y and 10y yields, CPI.
- Yields and rates report changes in percentage points; mixed selections are flagged rather
  than blended. Statistics apply to prices only.
- Caching is per source (ten minutes for headlines, an hour for yields, six hours for macro
  and company facts, a day for catalogs; on-chain rounds for the process lifetime), and
  concurrent identical requests are coalesced.

## Breaking changes

- **Symbol universe.** Yahoo tickers such as `^GSPC`, `AAPL` (as a price), `CL=F` or
  `BTC-USD` are gone. Prices exist only for instruments with an on-chain feed; use
  `search_markets` to discover them, and `company_fundamentals` for companies without one.
- `research_asset` and `compare_assets` drop `adjusted_close`/`return_basis`; there is no
  corporate-action adjustment for oracle prices.
- Response keys changed: `latest.value` replaces `latest_price.value`; `period_performance`
  carries `measure` (`percent` or `points`) and `change` for yields; `assets[].unit` names
  the unit; `market_overview` returns `assets` with `available`.
- `nomina://sources` and the manifest privacy policy list the new sources; Yahoo's privacy
  policy is no longer referenced.

## Install

- Hosted: add `https://nomina-mcp.onrender.com/mcp` as a custom connector in Claude, or
  `claude mcp add --transport http nomina https://nomina-mcp.onrender.com/mcp`.
- Claude Desktop: download `Nomina.mcpb` from the release and install it via Settings →
  Extensions → Advanced settings → Install Extension.
- Claude Code or any stdio client: `uv run --frozen --no-dev --directory <clone> server.py`.
- Gemini CLI: `gemini extensions install https://github.com/nomina-xyz/nomina-mcp`.
- Self-hosted: `docker run --rm -p 8000:8000 ghcr.io/nomina-xyz/nomina-mcp:2.0.0`, then
  connect a Streamable HTTP client to `http://localhost:8000/mcp`.

## Limits

Oracle prices are aggregates that update on heartbeat or deviation and can lag exchange
closes; on-chain history starts when a feed launched; no individual stock prices beyond the
equities with feeds; headlines are GDELT records, not article text, and GDELT throttles. A
year of daily on-chain closes takes about ten seconds to reconstruct on first request.
See [Data sources and limits](https://nomina-xyz.github.io/nomina-mcp/data-sources/).

## Verify

```sh
curl -s -X POST https://nomina-mcp.onrender.com/mcp \
  -H 'content-type: application/json' -H 'accept: application/json, text/event-stream' \
  -H 'mcp-protocol-version: 2025-06-18' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}' | jq '.result.tools[].name'
```

Expected: `search_markets`, `research_asset`, `compare_assets`, `market_overview`,
`company_fundamentals`.
