# Nomina v2.0.6

v2.0.6 adds a terms-of-use page and a domain-verification endpoint used by plugin
directories. Tools, symbols, and the MCP endpoint are unchanged.

## What's new

- [Terms of use](https://nomina-xyz.github.io/nomina-mcp/terms/): what the service is and is
  not (research data, not advice), acceptable use, availability, disclaimers.
- `GET /.well-known/openai-apps-challenge` on the HTTP server returns the verification token
  set in `OPENAI_APPS_CHALLENGE` (404 when unset), so OpenAI's plugin directory can verify
  control of `mcp.nomina.io`.

## Install

- Hosted: add `https://mcp.nomina.io/mcp` as a custom connector in Claude, or
  `claude mcp add --transport http nomina https://mcp.nomina.io/mcp`.
- Claude Desktop: download `Nomina.mcpb` from the release and install it via Settings →
  Extensions → Advanced settings → Install Extension.
- Claude Code or any stdio client: `uv run --frozen --no-dev --directory <clone> server.py`.
- Gemini CLI: `gemini extensions install https://github.com/nomina-xyz/nomina-mcp`.
- Self-hosted: `docker run --rm -p 8000:8000 ghcr.io/nomina-xyz/nomina-mcp:2.0.6`, then
  connect a Streamable HTTP client to `http://localhost:8000/mcp`.

## Verify

```sh
curl -s -o /dev/null -w '%{http_code}\n' https://mcp.nomina.io/.well-known/openai-apps-challenge  # 404 until a token is set
```
