# Nomina v1.0.0

Nomina is a read-only MCP server for financial markets research: ticker search, sourced
price history, and date-aligned comparisons over Yahoo Finance's public endpoints, with no
API key, account, or trading access. v1.0.0 ships as a Claude Desktop extension, is listed in
the official MCP Registry as `io.github.nomina-xyz/nomina-mcp`, and appears in the Gemini
CLI extension gallery.

## What's new

- `search_markets`: symbols and dated headlines for a company, asset, sector, or topic.
- `research_asset`: quote, period return, dated price history, and related news for one symbol.
- `compare_assets`: 2–6 symbols aligned on shared session dates, local currencies, explicit
  adjusted-vs-raw basis.
- Resource `nomina://sources` and prompt `research_brief`.
- Manifests for the MCP Registry (`server.json`), Gemini CLI (`gemini-extension.json`), and
  Agent Plugins (`plugin.json`, `mcp.json`).

## Install

- Claude Desktop: download `Nomina.mcpb` from the release and install it via Settings →
  Extensions → Advanced settings → Install Extension.
- Claude Code or any stdio client: `uv run --frozen --no-dev --directory <clone> server.py`.
- Gemini CLI: `gemini extensions install https://github.com/nomina-xyz/nomina-mcp`.

## Limits

Yahoo Finance's public endpoints can be delayed, incomplete, or rate limited, and its terms
restrict automated collection and redistribution — see
[Data sources and limits](https://nomina-xyz.github.io/nomina-mcp/data-sources/).
