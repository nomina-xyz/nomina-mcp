# Nomina v2.0.5

v2.0.5 prepares the hosted server for a custom hostname and gives it a landing page. Tools,
symbols, and the MCP endpoint are unchanged.

## What's new

- `--public-host` / `PUBLIC_HOST` accept a comma-separated list of hostnames, and the
  platform's `RENDER_EXTERNAL_HOSTNAME` is always accepted, so `mcp.nomina.io` can be served
  alongside `nomina-mcp.onrender.com`. Any other `Host` header is still rejected (HTTP 421).
- `GET /` returns a small HTML page naming the server, the `/mcp` endpoint, docs, privacy
  policy and source, with a `<link rel="icon">` so favicon fetchers that read the root page
  find Nomina's mark.

## Install

- Hosted: add `https://nomina-mcp.onrender.com/mcp` as a custom connector in Claude, or
  `claude mcp add --transport http nomina https://nomina-mcp.onrender.com/mcp`.
- Claude Desktop: download `Nomina.mcpb` from the release and install it via Settings →
  Extensions → Advanced settings → Install Extension.
- Claude Code or any stdio client: `uv run --frozen --no-dev --directory <clone> server.py`.
- Gemini CLI: `gemini extensions install https://github.com/nomina-xyz/nomina-mcp`.
- Self-hosted: `docker run --rm -p 8000:8000 ghcr.io/nomina-xyz/nomina-mcp:2.0.5`, then
  connect a Streamable HTTP client to `http://localhost:8000/mcp`.

## Verify

```sh
curl -s https://nomina-mcp.onrender.com/ | grep -o '<link rel="icon"[^>]*>'
```
