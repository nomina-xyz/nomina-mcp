# Nomina v2.0.8

v2.0.8 hardens the hosted server ahead of launch. Tools, symbols, and the MCP endpoint are
unchanged.

## What's new

- `/mcp` accepts only `POST`; the standalone `GET` event stream is not offered (HTTP 405, as the
  Streamable HTTP specification allows), so idle connections cannot pile up.
- Request bodies to `/mcp` are capped at 64 KiB (HTTP 413).
- The server bounds concurrent connections and keep-alive idle time.
- The container runs as an unprivileged user with a read-only application directory.
- Dependency refresh: PyJWT 2.15.1 (transitive, unused at runtime).
- The release pipeline pins the MCP Registry publisher binary by version and checksum.

## Install

- Hosted: add `https://mcp.nomina.io/mcp` as a custom connector in Claude, or
  `claude mcp add --transport http nomina https://mcp.nomina.io/mcp`.
- Claude Desktop: download `Nomina.mcpb` from the release and install it via Settings →
  Extensions → Advanced settings → Install Extension.
- Claude Code or any stdio client: `uv run --frozen --no-dev --directory <clone> server.py`.
- Gemini CLI: `gemini extensions install https://github.com/nomina-xyz/nomina-mcp`.
- Self-hosted: `docker run --rm -p 8000:8000 ghcr.io/nomina-xyz/nomina-mcp:2.0.8`, then
  connect a Streamable HTTP client to `http://localhost:8000/mcp`.

## Verify

```sh
curl -s -o /dev/null -w '%{http_code}\n' https://mcp.nomina.io/mcp   # 405: GET is not offered
```
