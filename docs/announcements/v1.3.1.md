# Nomina v1.3.1

v1.3.1 completes the extension manifest's metadata; the server, tools, and transports are
identical to v1.3.0.

## What's new

- `manifest.json` now carries `author.url`, `repository`, `homepage`, `documentation`,
  `support`, and `license`, so directories and clients can show where Nomina lives, where
  it is documented, and where to report problems.
- The bundle now includes `nomina/http.py`, so `server.py --transport streamable-http`
  works from an unpacked bundle as well as from a clone.

## Install

- Claude Desktop: download `Nomina.mcpb` from the release and install it via Settings →
  Extensions → Advanced settings → Install Extension.
- Claude Code or any stdio client: `uv run --frozen --no-dev --directory <clone> server.py`.
- Gemini CLI: `gemini extensions install https://github.com/nomina-xyz/nomina-mcp`.
- Self-hosted: `docker run --rm -p 8000:8000 ghcr.io/nomina-xyz/nomina-mcp:1.3.1`, then
  connect a Streamable HTTP client to `http://localhost:8000/mcp`.

## Limits

Yahoo Finance's public endpoints can be delayed, incomplete, or rate limited, and its terms
restrict automated collection and redistribution — see
[Data sources and limits](https://nomina-xyz.github.io/nomina-mcp/data-sources/).
