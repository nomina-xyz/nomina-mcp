# Nomina v2.0.4

v2.0.4 serves Nomina's icon from the HTTP server so MCP hosts that display a connector's
favicon (Claude among them) show Nomina's mark instead of a placeholder. Tools, symbols, and
transports are unchanged.

## What's new

- `GET /favicon.ico` and `GET /icon.png` on the Streamable HTTP server return the same 256×256
  PNG the desktop bundle ships, with a one-day cache header. The container image now includes it.

## Install

- Hosted: add `https://nomina-mcp.onrender.com/mcp` as a custom connector in Claude, or
  `claude mcp add --transport http nomina https://nomina-mcp.onrender.com/mcp`.
- Claude Desktop: download `Nomina.mcpb` from the release and install it via Settings →
  Extensions → Advanced settings → Install Extension.
- Claude Code or any stdio client: `uv run --frozen --no-dev --directory <clone> server.py`.
- Gemini CLI: `gemini extensions install https://github.com/nomina-xyz/nomina-mcp`.
- Self-hosted: `docker run --rm -p 8000:8000 ghcr.io/nomina-xyz/nomina-mcp:2.0.4`, then
  connect a Streamable HTTP client to `http://localhost:8000/mcp`.

## Verify

```sh
curl -sI https://nomina-mcp.onrender.com/favicon.ico | grep -i 'content-type: image/png'
```
