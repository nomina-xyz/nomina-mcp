# Nomina v1.1.0

v1.1.0 adds the documentation and disclosures that MCP directories check before listing a
server: a docs site with install guides and a tool reference, Nomina's own privacy policy, and
complete tool annotations. Tool behavior is unchanged.

## What's new

- Docs site at <https://nomina-xyz.github.io/nomina-mcp/>: install guides for Claude
  Desktop, stdio clients, Gemini CLI, Agent Plugins, and the MCP Registry; a tool reference
  with parameter constraints and response keys; data-source limits and branding provenance.
- Privacy policy at <https://nomina-xyz.github.io/nomina-mcp/privacy/>, referenced from the
  extension manifest and the `nomina://sources` resource alongside Yahoo's policy.
- Every tool now declares `readOnlyHint: true`, `destructiveHint: false`,
  `idempotentHint: true`, `openWorldHint: true` (previously `destructiveHint` was left to the
  spec default of `true`).
- The server reports its website and icon in `serverInfo`, and every manifest is held to one
  version by the bundle build.

## Install

- Claude Desktop: download `Nomina.mcpb` from the release and install it via Settings →
  Extensions → Advanced settings → Install Extension.
- Claude Code or any stdio client: `uv run --frozen --no-dev --directory <clone> server.py`.
- Gemini CLI: `gemini extensions install https://github.com/nomina-xyz/nomina-mcp`.

## Limits

Yahoo Finance's public endpoints can be delayed, incomplete, or rate limited, and its terms
restrict automated collection and redistribution — see
[Data sources and limits](https://nomina-xyz.github.io/nomina-mcp/data-sources/).
