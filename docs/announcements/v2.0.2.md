# Nomina v2.0.2

v2.0.2 makes Nomina's use of the Bureau of Labor Statistics API stay within its published
allowance by construction. Tools, symbols, and transports are unchanged.

## What's new

- BLS v1 allows 25 requests per day per IP address. Nomina now requests all four macro series
  together in ten-year blocks anchored at the current year, so every symbol and every
  period or date window shares the same cached responses (at most three, refreshed every six
  hours) instead of one request per symbol and year range. A process-wide counter refuses to
  send more than 25 requests in a day and reports the exhausted allowance as an explicit
  error rather than exceeding it, including when BLS itself is failing (errors are not
  cached).
- Monthly points are returned in date order regardless of how BLS orders blocks.

## Install

- Hosted: add `https://nomina-mcp.onrender.com/mcp` as a custom connector in Claude, or
  `claude mcp add --transport http nomina https://nomina-mcp.onrender.com/mcp`.
- Claude Desktop: download `Nomina.mcpb` from the release and install it via Settings →
  Extensions → Advanced settings → Install Extension.
- Claude Code or any stdio client: `uv run --frozen --no-dev --directory <clone> server.py`.
- Gemini CLI: `gemini extensions install https://github.com/nomina-xyz/nomina-mcp`.
- Self-hosted: `docker run --rm -p 8000:8000 ghcr.io/nomina-xyz/nomina-mcp:2.0.2`, then
  connect a Streamable HTTP client to `http://localhost:8000/mcp`.

## Verify

Research `CPI`, then `UNRATE`, then `PAYEMS` in one session and observe a single request to
`api.bls.gov` (for example with the stdio server behind an HTTP proxy); see
[Data sources and limits](https://nomina-xyz.github.io/nomina-mcp/data-sources/).
