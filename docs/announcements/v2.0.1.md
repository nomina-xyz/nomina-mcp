# Nomina v2.0.1

v2.0.1 completes the source-terms review for the v2 data layer. Tools, symbols, and
transports are unchanged.

## What's new

- Responses that include Bureau of Labor Statistics data now carry the statement BLS's
  [API terms](https://www.bls.gov/developers/termsOfService.htm) require — "BLS.gov cannot
  vouch for the data or analyses derived from these data after the data have been retrieved
  from BLS.gov" — in `caveats`, next to `retrieved_at`. This applies to `research_asset` and
  `compare_assets` with a BLS series and to every `market_overview` (CPI is in the basket).
- `nomina://sources` and [Data sources and limits](https://nomina-xyz.github.io/nomina-mcp/data-sources/)
  state each source's actual basis and obligations: public-domain US government statistics
  (17 U.S.C. § 105; SEC fair-access `User-Agent` and rate; BLS citation and 25 requests/day),
  public Ethereum state read through free public RPC gateways (PublicNode, MEV Blocker) with
  paced and rate-limit-aware requests, Chainlink's Terms of Service covering only its feed
  directory, and GDELT's open release with citation. Blanket "licensed for display and
  redistribution" wording has been removed.

## Install

- Hosted: add `https://nomina-mcp.onrender.com/mcp` as a custom connector in Claude, or
  `claude mcp add --transport http nomina https://nomina-mcp.onrender.com/mcp`.
- Claude Desktop: download `Nomina.mcpb` from the release and install it via Settings →
  Extensions → Advanced settings → Install Extension.
- Claude Code or any stdio client: `uv run --frozen --no-dev --directory <clone> server.py`.
- Gemini CLI: `gemini extensions install https://github.com/nomina-xyz/nomina-mcp`.
- Self-hosted: `docker run --rm -p 8000:8000 ghcr.io/nomina-xyz/nomina-mcp:2.0.1`, then
  connect a Streamable HTTP client to `http://localhost:8000/mcp`.

## Verify

```sh
curl -s -X POST https://nomina-mcp.onrender.com/mcp \
  -H 'content-type: application/json' -H 'accept: application/json, text/event-stream' \
  -H 'mcp-protocol-version: 2025-06-18' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"market_overview","arguments":{}}}' \
  | jq -r '.result.content[0].text | fromjson | .caveats[]' | grep vouch
```
